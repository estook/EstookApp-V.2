# La Evolución ya no es un documento aparte

Se escribió para decir, en un solo sitio, hacia dónde cambiaba Estook: de aplicación de gestión a sistema operativo del restaurante, y de no cobrar a cobrar. **Ese cambio ya está dentro de los demás documentos**, y tenerlo escrito dos veces hacía que alguno se quedase atrás ([decisión 0063](../decisiones/0063-una-fuente-por-tema.md)).

**Este fichero se queda** para que ningún enlace de una decisión antigua se rompa. Si una decisión dice «Evolución, capítulo 11.1», aquí pone dónde leerlo hoy.
