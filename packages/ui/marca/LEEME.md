# Marca

Aqui viven los recursos oficiales de identidad. Los ficheros todavia no estan: los
tiene Richi y hay que dejarlos caer en esta carpeta.

| Fichero                  | Que es                                |
| ------------------------ | ------------------------------------- |
| `estook-logo.svg`        | El logo horizontal, con el claim      |
| `estook-simbolo.svg`     | La marca sola (la E de tres barras)   |
| `estook-logo-blanco.svg` | El mismo logo para fondos oscuros     |
| `fogon.svg`              | El simbolo de Fogon, la mascota de IA |
| `favicon.svg`            | El favicon                            |
| `favicon.ico`            | El favicon para navegadores antiguos  |
| `apple-touch-icon.png`   | 180 px                                |
| `pwa-192.png`            | Icono de aplicacion instalable        |
| `pwa-512.png`            | Icono de aplicacion instalable        |

Todo en SVG salvo lo que el sistema operativo exija en PNG (C5 del Plan).

Los colores de marca, para que no se inventen: charcoal `#111C1F`, naranja
`#FF7A00`, blanco y negro. Estan tambien en las fichas de diseno de B1, que se
escriben en M3.

Los componentes que consumen esto se construyen en **M3**, no antes.
